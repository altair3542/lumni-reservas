# A4 — Frontend React: cotizador, wizard y administrador

**Dependencia:** A0 para shell; A1 para quote; A2 para wizard; A3 para admin. **Trabajo en dos fases** A4a y A4b; el frontend no inventa estado de backend.

## Leer
`CONTRATOS_Y_MODELO.md` y matriz R04, R11–R16, R22–R25, R29, R34–R38, R45. Componentes reciben datos del API client tipado.

## A4a — Shell, sesión, cotizador
- Rutas de login/logout, catálogo de salas y formulario de fecha/hora/duración. Resultado muestra tarifa base, descuento, recargo sábado, extras y total.
- Cuando `canBook=false`, mostrar motivo y `suggestedSlot` solo cuando el API lo entregue; ofrecer ajustar antes de reservar.
- Manejar loading/error/credenciales caducadas y zonas en Colombia sin depender de timezone del equipo.

## A4b — Wizard y administración
- Tres pasos claros: datos cliente → sala/horario prellenado → extras (proyector, café o ninguno). Persistir **cada paso** con PATCH, `expectedVersion`; bloquear navegación hasta que el save termine o mostrar error. Retoma desde datos del servidor tras cerrar pestaña.
- Confirmar mediante botón explícito de la aplicación y endpoint `/confirm`. Mostrar 409 slot-taken y permitir recotizar; no asumir que quote reserva cupo. Mostrar estado confirmado/snapshot.
- Admin: tabla paginada con filtros por estado/sala, detalle, cancelar con motivo obligatorio, estado de correo incl. failed, capturas locales; ocultar para cliente, manteniendo seguridad real en backend.
- A6 es dueño del chat; colaborar con su ruta/UI pero no implementar lógica de IA en React.

## Aceptación y pruebas
- Cliente cotiza y persiste 3 pasos, cierra navegador, reingresa y retoma sin pérdida; no se pasa del paso actual mientras el servidor no confirme guardado.
- Intento manual de admin desde cliente da 403 real; cancelación sin motivo falla también en backend.
- Error de concurrencia informa que la hora dejó de estar disponible; quote contiene razón y siguiente slot.
- A4a puede comenzar en paralelo con A1; A4b solo con contratos estables de A2/A3. Capturas para README, reportar evidencia real.
