7. Actualizar `docs/decisiones.md`, `docs/ai-log.md` y `AGENTS.md` ya presentes conforme a archivos reales; crear `.env.example`, README de aplicación (ampliando el actual) y CI. Actualizar `PROGRESO.md` con evidencia.

## Aceptación binaria
- Un clon limpio puede instalar deps, levantar PostgreSQL, migrar, sembrar e iniciar API+web con comandos documentados.
- La tabla `bookings` acepta draft incompleto y **rechaza** por BD dos confirmadas solapadas; muestra consulta `pg_constraint`/`\d bookings` ejecutada.
- Las semillas se ejecutan dos veces sin duplicar datos; dos roles pueden autenticarse; Zod rechaza input inválido.
- Tests unitarios de shared y smoke API, `lint`, `typecheck`, y CI (si se ejecuta) documentados; nunca afirmar verde sin logs.
